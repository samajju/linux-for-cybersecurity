Lesson 3: File System & Basic Commands

Linux File System Structure

Linux uses a hierarchical file system starting from the root directory:

/
  • /home – User directories
  • /root – Root user home
  • /etc – Configuration files
  • /var – Logs and variable data
  • /tmp – Temporary files
  • /bin – Essential system commands

Navigation Commands

pwd – Show current directory

ls – List files

cd – Change directory

Practice:

pwd
ls
cd /
ls
cd home
pwd

File Operations

mkdir foldername – Create directory

touch filename – Create file

cp source destination – Copy file

mv oldname newname – Move or rename file

rm filename – Delete file

clear – Clear terminal screen

Practice Challenge:

mkdir cyberlab
cd cyberlab
touch file1.txt
cp file1.txt backup.txt
mv backup.txt renamed.txt
ls

Mini Real-World Scenario

You are organizing security logs. Create a folder named logs, create 3 files inside it, and rename one file.

mkdir logs
cd logs
touch log1.txt log2.txt log3.txt
mv log3.txt system_log.txt
ls
