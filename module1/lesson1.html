Lesson 1: What is Linux?

What is an Operating System?

An Operating System (OS) is software that manages hardware and allows users to interact with a computer.

Examples: Windows, macOS, Linux.

What is Linux?

Linux is an open-source operating system kernel created by Linus Torvalds in 1991.

It powers servers, cloud systems, embedded devices, and cybersecurity tools.

Linux Distributions

  • Ubuntu – Beginner friendly
  • Debian – Stable server distribution
  • Kali Linux – Used for penetration testing

Why Linux is Important in Cybersecurity

  • Most web servers run Linux
  • Full control through terminal
  • Powerful networking tools
  • Native support for security tools

Practical Task

Open terminal and run:

uname -a

This command displays system information.
