Lesson 2: Setting Up Kali Linux Lab

Why You Need a Lab

Cybersecurity requires practice. A virtual lab allows you to experiment safely without affecting your real system.

Step 1: Install VirtualBox

Download and install VirtualBox from the official website.

Step 2: Download Kali Linux

Download the Kali Linux ISO file from the official Kali Linux website.

Step 3: Create Virtual Machine

  1. Click New
  2. Select Linux
  3. Choose Debian (64-bit)
  4. Allocate at least 4GB RAM
  5. Create 40GB virtual disk

Practical Task

Install Kali Linux and open the terminal.

Run:

uname -a

Take a screenshot as proof.
