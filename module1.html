Module 1: Linux Basics for Cybersecurity

Objective

By the end of this module, students will understand Linux fundamentals and use essential terminal commands confidently.

Lesson 1: What is Linux?

Linux is an open-source operating system used in servers, cybersecurity, cloud infrastructure, and ethical hacking.

Why Linux is Important in Cybersecurity

  • Most servers run Linux
  • Kali Linux is used for penetration testing
  • Full system control through terminal
  • Powerful scripting capabilities

Lesson 1.2 – Setting Up Your Lab

To practice cybersecurity, you need a lab environment.

  1. Download VirtualBox
  2. Download Kali Linux ISO
  3. Create new virtual machine
  4. Allocate minimum 4GB RAM
  5. Install Kali Linux

Practical Task: Install Kali and open terminal.

Lesson 3: File System & Basic Commands

Important directories in Linux:

  • /home – User files
  • /root – Root user directory
  • /etc – Configuration files
  • /bin – Essential system commands
  • /var – Log files
  • /tmp – Temporary files

Practice:

cd /
ls
cd home
pwd
#
